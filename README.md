# The Start Machine — лендинг-визитка

Сайт: https://aevkone.github.io/vizitka/ (закрыт от поисковиков, показываем при личном знакомстве).

## Что на странице
1. Первый экран и кнопка «Обсудить проект» → Telegram @valeria_chirkova
2. 8 направлений: готовый бизнес, готовые системы, Контент-завод, сайты и лидген, промо-ролики, сопровождение, усиление бизнеса (подкаст, мероприятия, выступления), разработка под заказ
3. Команда: Антон Кочергин и Валерия Чиркова
4. Реквизиты ИП Чиркова В.В. и юридические документы

## Файлы
- `index.html` — вся страница (стили и скрипты внутри)
- `privacy.html`, `consent.html`, `terms.html`, `legal.css` — документы
- `img/` — скриншоты проектов и фото, `video/` — промо-ролики, `fonts/` — Oswald и Onest (SIL OFL 1.1)

## Как обновить
Правите файлы, затем `git add -A && git commit -m "..." && git push`. Через 1–2 минуты GitHub Pages обновит сайт.
